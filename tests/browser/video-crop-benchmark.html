Fixed camera crop benchmark

Run the approved 1280×720 at 30 fps capture-only, pass-through, and fixed-crop measurements on a reference camera. Results stay in this browser until you download them.

Reference device details

The camera is requested only when you start it. The run uses your default camera and releases all session tracks when it finishes or when you stop. No camera IDs or media are uploaded; JSON is saved only when you download it.

For latency measurement, center the animated marker in the camera view. Use an external display for an integrated camera, or open the synchronized marker window below. The final retention phase briefly stops and restarts capture five times.

Run protocol

  1. Enter the commit SHA, host/device description, and Node/package-manager versions.
  2. Start the camera, grant permission, and frame the marker in the preview.
  3. Run three warmed trials of capture-only, pass-through, and fixed crop.
  4. Run five warm crop add/update/bypass/remove cycles and five session stop/start cycles.
  5. Review the JSON, download it, and keep the physical-device evidence with TASK-1.25.

The marker-to-preview samples provide an optical source-to-preview latency measurement. A run with too few decoded marker samples records latency as unknown. Presented-frame gaps describe frames missed by the browser's video-frame callback; they do not detect source frames the camera never delivered.
